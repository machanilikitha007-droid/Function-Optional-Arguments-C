# Function Arguments in C

This program demonstrates passing different types of arguments to a
function. C does not support default arguments, so all required
arguments are passed when the function is called.

## File

optional_arguments.c

## Concepts Used

- Function arguments
- Function parameters
- Function call
- Character array
- Integer parameter

## How to Run

gcc optional_arguments.c -o optional_arguments
./optional_arguments
